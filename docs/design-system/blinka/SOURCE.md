# Origen

Sistema de diseño de referencia entregado por el equipo (export de OpenDesign a partir de blinka.co). Se guardan
reglas, tokens, previews, kit aplicado, fuentes (Inter y Geist Mono, licencia OFL) y dos capturas de referencia.
No se copian los logos de Blinka ni de sus socios, la ilustración grabada ni el bundle del sitio: pertenecen a sus
dueños. Por eso algunas imágenes de `preview/` y `ui_kits/` no cargan.

Custodio usa este sistema como lenguaje visual (tokens, tipografía, radios, sombras, botones), con su propio logo.
