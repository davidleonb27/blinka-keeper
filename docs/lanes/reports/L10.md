### 2. Autoalojamiento con un comando

- `apps/api/Dockerfile`: `python:3.12-slim`, `uv` 0.11.32 fijado, `uv sync --locked --no-dev` (dependencias primero
  para la caché), usuario sin privilegios `custodio` (uid 10001), `EXPOSE 8000`, `HEALTHCHECK` a `/api/v1/health` y
  `CMD` que migra y arranca `uvicorn main:app`.
- `python -m custodio.db.migrate` (nuevo, `custodio/db/migrate.py`): migra `DATABASE_URL` con el mismo candado
  consultivo de Postgres que ya usaba la app, así que varias réplicas pueden arrancar a la vez. Con test.
- `uvicorn` pasó de dependencia de desarrollo a dependencia de ejecución (el contenedor la necesita; `uv.lock`
  regenerado, sólo cambia esa línea).
- `apps/web/Dockerfile`: `node:24-slim` en dos etapas, `npm ci`, `next build` con `API_INTERNAL_URL` como argumento de
  construcción (Next.js fija los rewrites al construir) y variable de ejecución, `npm prune --omit=dev`, usuario `node`,
  `EXPOSE 3000`, `HEALTHCHECK`, `next start`.
- Ambos Dockerfiles aceptan un secreto opcional de BuildKit `extra_ca` para redes con un proxy que intercepta HTTPS (es
  el caso de este entorno); si no se pasa, se ignora. `.dockerignore` en ambas apps.
- `docker-compose.yml` en la raíz: `postgres:16` con volumen `custodio-data` y `healthcheck` (`pg_isready`); `api` con
  `DATABASE_URL` al Postgres del compose, espera a `service_healthy`, migra al arrancar y tiene `healthcheck`; `web` con
  `API_INTERNAL_URL=http://api:8000`, espera a que la API esté sana.
- `.env.example` en la raíz con cada variable explicada (y `!.env.example` en `.gitignore`, que antes lo ignoraba).
- CI: job `images` que corre `docker compose config -q` y construye las dos imágenes con caché de GitHub Actions.
- **Sin `ANTHROPIC_API_KEY` no era cierto lo pedido** y ahora sí (TDD, ver abajo):
  - Antes: `POST /firewall/intents` y `POST /policy/compile` respondían **500** (`TypeError` del SDK al no tener
    credenciales, que no es `LLMError`), y el firewall dependía del modelo para leer la intención.
  - Ahora: `llm.structured` lanza `LLMNotConfigured` antes de llamar al SDK. Los servicios lo traducen a
    `ModelNotConfigured` → **503 `model_not_configured`** con «Esta función requiere ANTHROPIC_API_KEY…». El red team
    emite ese mismo mensaje; la narración del acta se omite como antes.
  - Nuevo lector determinista `custodio/extraction/labels.py`: sin clave, el texto y los PDF con texto se leen por
    líneas `Campo: valor` (Proveedor, NIT/RFC/CNPJ…, Número de factura, Fecha de emisión/vencimiento, Total a
    pagar/Monto, Moneda, Banco, Cuenta, Concepto). La **primera** línea que dice cada dato gana (la cabecera de una
    intención de pago no la puede pisar un documento adjunto); cada valor pasa por la misma verificación de citas que la
    lectura del modelo (`verify.verified_field`); lo que ninguna etiqueta dice queda sin leer y R1 lo escala; un «$»
    sin código no da moneda. Con clave, todo sigue igual que antes.
  - Una imagen o un PDF escaneado sin clave responde 503 y no guarda nada (la transacción se revierte), en vez de
    quedar como factura «sin leer».

### 4. Sitio de código abierto (estructura tipo supabase.com, texto y marca propios)

- Portada nueva en `/` (`apps/web/src/app/page.tsx`), oscura o clara según el sistema y con el selector de tema, con
  acento verde esmeralda en un ámbito `.site` (no cambia el resto de la app): hero «El agente de cuentas por pagar de
  código abierto» con «Probar la demo» y «Autoalojar en 1 comando», bloque de código con `docker compose up --build` y un
  `curl` al firewall; «Medido, no prometido» (0 pagos indebidos en 1.000 empresas simuladas y 25.139 facturas; 36/36 en
  el dataset dorado; 12 reglas), con enlace a cómo se midió; cuadrícula de las seis funciones pedidas con enlace a su
  documentación; «Cómo decide» (con la línea del riel de L9 y el acta de ejemplo); «Código abierto» con las estrellas de
  GitHub; «Autoalójalo» (compose, Vercel + Neon, Railway/Fly/VPS); llamada final y pie con enlaces. Sin clientes,
  logos de empresas ni testimonios.
- Estrellas de GitHub: se piden **en el servidor** a la API pública (`fetchStarCount`, con 3 s de tiempo límite) dentro
  de `"use cache"` con `cacheLife("hours")`. El navegador nunca llama a GitHub (no hay límites por IP ni errores en la
  consola) y, si GitHub falla, el botón queda como «Estrella en GitHub» sin inventar un número.
- `/docs` con barra lateral (fija en escritorio, fila desplazable en el teléfono que centra la página actual):
  Introducción, Inicio rápido (demo, autoalojado con ancla `#autoalojado`, nube, desarrollo), Configuración (todas las
  variables y qué funciona sin modelo), Reglas R1–R12 (tabla desde `RULES`), Modelo de seguridad e invariantes, Firewall
  por API, MCP (Claude Desktop y Claude Code), Rieles de pago (cómo escribir uno nuevo con el protocolo de
  `payments/port.py`), Referencia de la API (enlace a `/api/v1/docs` y `openapi.json`) y Contribuir. Páginas anterior y
  siguiente en cada una.
- Se quitó `components/landing/live-metrics.tsx`: la portada ya no crea un espacio de trabajo al visitarla.
- `CodeBlock` ahora da nombre accesible a su `figure`. El pie usa un solo landmark «Pie de página» (antes tenía uno
  llamado «Documentación», que chocaba con la barra lateral).
- e2e de L8 actualizado: la portada nueva y un paso que recorre las 10 páginas de `/docs` comprobando su barra lateral.

### Tipografía (pedido del dueño, para toda la web)

- Test de contrato `src/app/typography.test.ts`: el par exacto en `layout.tsx`, los tokens una sola vez y ninguna otra
  fuente ni alias en `src/`.

- La portada dejó de mostrar métricas en vivo del espacio (creaban un espacio por visita) y muestra las cifras medidas

- El código de conducta usa un reporte privado por GitHub o un mensaje a @davidleonb27 como canal; si el dueño prefiere
  un correo, se cambia en una línea.
